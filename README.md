# Sprint_6

Проект автоматизации тестирования сервиса «Яндекс Самокат».

## Что проверяется

- Выпадающий список в разделе «Вопросы о важном».
- Оформление заказа самоката через верхнюю кнопку «Заказать».
- Оформление заказа самоката через нижнюю кнопку «Заказать».
- Успешное создание заказа.
- Переход на главную страницу при клике на логотип «Самокат».
- Переход на страницу Дзена при клике на логотип Яндекса.

## Структура проекта

- locators/ — локаторы элементов.
- pages/ — Page Object классы.
- tests/ — автотесты.
- conftest.py — фикстура браузера.
- urls.py — ссылки проекта.
